# AdSense 재심사 준비 기록 — 2026-09-23

## 판단

정적 페이지 자체는 승인 방해 요인이 아니다. 검색 엔진과 광고 검토 시스템이 읽을 수 있는 완성된 HTML은 오히려 접근성에 유리하다. 이번 정비는 공개 콘텐츠의 고유 가치, 작성 책임, 출처와 계산 과정, 사이트 소유 확인을 더 분명하게 만드는 데 초점을 맞췄다.

## 이번에 보강한 항목

- 사이트 전체에 `google-adsense-account` 메타 태그와 WebSite·Organization 구조화 데이터를 추가했다.
- 기존 `ads.txt`의 게시자 ID와 메타 태그의 게시자 ID가 일치하도록 점검한다.
- 가이드와 답변에 작성·최종 검수 주체, 검수일, 공식·공공 출처 수를 표시한다.
- 답변 페이지에도 Article 구조화 데이터와 인용 출처를 추가한다.
- 구매 절차, 월납입금, 3년 총비용, 보조금 신청, 아파트 충전 등 대표 가이드 5편에 사이트 자체 계산·의사결정 표를 추가했다.
- 운영자 소개와 콘텐츠 정책에 AI 보조 범위, 사람의 최종 검수, 오류 정정 절차를 구체적으로 공개했다.
- `npm run content:audit`에 AdSense 재심사 준비 점검을 연결했다.

## 재심사 요청 직전 수동 확인

1. 배포된 `https://www.paytesla.kr/ads.txt`가 브라우저에서 열리고 게시자 ID가 AdSense 계정과 일치하는지 확인한다.
2. 홈페이지 소스에 `google-adsense-account` 메타 태그가 출력되는지 확인한다.
3. AdSense의 사이트 상태에서 도메인이 연결됨으로 표시되는지 확인한다.
4. 정책 센터에 별도 위반 항목이 없는지 확인한다.
5. 대표 가이드 5편과 소개·콘텐츠 정책·데이터 출처 페이지가 로그인 없이 열리는지 확인한다.
6. 위 항목을 확인한 뒤 AdSense에서 재검토를 요청한다.

## 운영 주의

- 심사 중에는 출처 검수 없이 글 수만 늘리지 않는다.
- 정책·가격·보조금 숫자를 바꾸면 관련 계산기와 가이드를 함께 검산한다.
- 검색 질문이나 AI 초안이 있어도 운영자의 출처 대조와 최종 검수 없이 공개하지 않는다.
