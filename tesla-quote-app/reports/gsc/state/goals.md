# paytesla 운영 목표

최상위 목표는 사용자가 소유한다. AI 운영 루프는 최상위 목표를 바꾸지 않고,
Search Console 근거에 따라 현재 병목과 중간 목표만 갱신한다.

## 최상위 목표

**테슬라·전기차 구매자가 실제 결정을 내리는 데 필요한 정보를 제공하고,
Google AdSense의 유용한 콘텐츠 기준을 충족해 승인을 받는다.**

## 마일스톤

| # | 마일스톤 | 상태 | 판단 기준 |
|---|---|---|---|
| 1 | 대표 구매 가이드 30편이 모두 공개·색인 가능하고 내부 순환을 갖춤 | 완료 | 콘텐츠 감사와 프로덕션 빌드 통과 |
| 2 | 구매 의도 검색어 5개 이상이 평균순위 10위 이내에서 클릭 발생 | 진행 | 28일 GSC 검색어·페이지 성과 |
| 3 | AdSense 재심사 승인 | 대기 | 콘텐츠 평가 기간과 정책 상태 확인 후 신청 |
| 4 | 월간 자연검색 클릭 100회 | 진행 전 | 28일 클릭 100회 이상 |

## 측정 가능한 것

- GSC 검색 노출·클릭·CTR·평균순위
- 사용자가 검색한 질문과 연결된 랜딩 페이지
- 코드 품질, 정적 페이지 수, 내부 링크, 공식 출처

현재 GA4 행동·AdSense 수익 데이터는 이 루프의 판정 근거로 사용하지 않는다.

## 출발점

2026-08-28 확정 데이터, 최근 28일 기준:

- 클릭 9회
- 노출 730회
- CTR 1.23%
- 평균순위 10.2
- 검색어 111개

## 현재 병목

### 2026-09-29 진단

**병목**: 비동결 대상 중 `/subsidy`가 28일간 1,152노출·7클릭·CTR 0.61%·평균 7.5위로
가장 큰 개선 여지를 보인다. 핵심 검색어 `테슬라 보조금 계산기`는 131노출·2클릭·CTR 1.53%·
평균 7.8위다. 다만 페이지는 이미 지역·트림 선택, 국고·지자체 보조금 적용, 실구매가와
월납입금 계산을 첫 화면에서 제공하고 홈·계산기 허브·지역 페이지·모델 페이지와 연결돼 있다.
현재 증거만으로는 독립 정적 페이지 공백이나 즉시 수정해야 할 단일 콘텐츠 결함을 특정하기 어렵다.

**근거**: 2026-08-30~09-26 검색어 차원은 13클릭·875노출·CTR 1.49%·평균 9.54위·
검색어 173개다. 페이지·디바이스 합계는 86클릭·11,253노출이다. 이전 비교 구간보다 검색어
클릭은 30.0%, 노출은 15.7% 증가했고 평균순위는 0.6위 개선됐다. Tesla 공식 Model 3·Model Y
페이지는 현재 판매 모델을 확인하는 기준이고, 무공해차 통합누리집은 지자체·차종·모델별 국비와
지방비 및 지급 현황을 공식 조회 경로로 제공한다. 기존 계산기와 공식 최종 확인 경로의 역할이
분리돼 있어 같은 질문을 새 URL로 반복할 근거는 부족하다.

**과거 결정 판정**: 판정 기일이 된 결정은 0건이다. 제주 보조금 D등급 실험은 2026-10-12,
구매 절차 대표 글 심화는 2026-10-26, 계산기 내부 순환은 2026-11-08이 첫 판정일이다.

**선택한 조치**: H등급 관찰. 열린 실험이 3건으로 상한에 도달했고 `/subsidy`의 기존 답변·
메타데이터·내부 순환이 검색 의도를 이미 포괄하므로 공개 콘텐츠, 계산 로직, 원본 데이터,
메타데이터, 내부 링크를 변경하지 않는다. 2026-09-26 관측만 기록하고 새 결정 JSON은 만들지 않는다.

**동결·다음 판단**: 제주 보조금 페이지와 대상 검색어는 2026-10-12까지, 구매 절차 글과
`테슬라 출고 예상 사이트`는 2026-10-26까지, 계산기 구조와 `테슬라 계산기`·`테슬라계산기`는
2026-11-08까지 동결한다. 다음 판정 전에는 신규 결정을 열지 않는다.
