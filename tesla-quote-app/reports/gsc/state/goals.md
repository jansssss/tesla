# paytesla 운영 목표

최상위 목표는 사용자가 소유한다. AI 운영 루프는 최상위 목표를 바꾸지 않고,
Search Console 근거에 따라 현재 병목과 중간 목표만 갱신한다.

## 최상위 목표

**테슬라·전기차 구매자가 실제 결정을 내리는 데 필요한 정보를 제공하고,
Google AdSense의 유용한 콘텐츠 기준을 충족해 승인을 받는다.**

## 마일스톤

| # | 마일스톤 | 상태 | 판단 기준 |
|---|---|---|---|
| 1 | 대표 구매 가이드 30편이 모두 공개·색인 가능하고 내부 순환을 갖춤 | 완료 | 콘텐츠 감사와 프로덕션 빌드 통과 |
| 2 | 구매 의도 검색어 5개 이상이 평균순위 10위 이내에서 클릭 발생 | 진행 | 28일 GSC 검색어·페이지 성과 |
| 3 | AdSense 재심사 승인 | 대기 | 콘텐츠 평가 기간과 정책 상태 확인 후 신청 |
| 4 | 월간 자연검색 클릭 100회 | 진행 전 | 28일 클릭 100회 이상 |

## 측정 가능한 것

- GSC 검색 노출·클릭·CTR·평균순위
- 사용자가 검색한 질문과 연결된 랜딩 페이지
- 코드 품질, 정적 페이지 수, 내부 링크, 공식 출처

현재 GA4 행동·AdSense 수익 데이터는 이 루프의 판정 근거로 사용하지 않는다.

## 출발점

2026-08-28 확정 데이터, 최근 28일 기준:

- 클릭 9회
- 노출 730회
- CTR 1.23%
- 평균순위 10.2
- 검색어 111개

## 현재 병목

### 2026-10-12 자동 운영 판단

**병목**: `/subsidy/seoul`은 28일간 1,536노출·8클릭·CTR 0.52%·평균 7.67위로
비동결 페이지 가운데 노출 대비 클릭 손실이 가장 크다. 연결된 앱과 로컬 페이지 집계가 같은
수치를 반환했다. `서울 테슬라 보조금`은 12노출·1클릭·CTR 8.33%·평균 6.92위지만,
소표본 검색어의 개선만으로 페이지 전체 저CTR이 해소됐다고 보기는 어렵다.

**근거**: GSC SEO & Content Planner의 확정 구간은 2026-09-12~10-09, 비교 구간은
2026-08-15~09-11이다. 사이트 전체는 143클릭·9,471노출·CTR 1.51%·평균 7.06위로,
비교 기간보다 클릭 64회 증가, 노출 183회 감소, CTR 0.69%p 증가, 평균순위 0.27위 개선이었다.
필터 없는 전체 비교 접근이며 약 3일의 확정 지연과 상위 반환 행 기반 분석이라는 제한이 있다.
로컬 GSC의 같은 확정 구간은 검색어 차원 24클릭·1,353노출·CTR 1.77%·평균 8.89위·검색어
222개다. 검색어 차원은 익명화 행을 포함하지 않아 사이트 전체 페이지 합계보다 작지만,
서울 페이지 수치와 저CTR 방향은 앱 결과와 일치한다.

**과거 결정 판정**: 제주 보조금 D등급 결정은 변경 후 확정 29일간 544노출·7클릭·CTR
1.29%·평균순위 5.1위였다. 기준선 CTR 1.14%보다 0.15%p 높았지만 목표인 CTR 2.0%
또는 클릭 20회에 미달했고, 500노출 이상에서 CTR 1.0% 미만이라는 반증 조건도 피했다.
사이트 전체 변화를 보정한 순위는 0.4위 개선되어 **변화없음**으로 닫았다.

**선택한 조치**: H등급 관찰. 서울 보조금의 검색결과 문구만 고친 과거 D등급 실험은 이미
빗나갔고, 제주도 같은 유형의 문구 변경이 변화없음으로 끝났으므로 메타데이터 수정을 반복하지
않는다. 현재 페이지는 차종별 보조금·차감 예상가, 조건·예외·FAQ와 보조금 계산기·Model 3·
Model Y·비교 페이지 왕복 링크를 제공한다. 서울시의 2026-09-14 추가 공고는 보급 물량 확대와
신청 기간·출고 등록 순 지급을 확인하지만 차량별 지급액 변경을 직접 뜻하지 않는다. 공개 콘텐츠,
메타데이터, 계산 로직·원본 데이터, 내부 링크는 변경하지 않고 새 정적 페이지도 만들지 않는다.

**동결·다음 판단**: 제주 결정을 닫아 열린 실험은 3건이 됐지만 상한에 도달해 신규 결정은
여전히 금지된다. 구매 절차 글은 2026-10-26, 충전 시간은 2026-10-27, 계산기 내부 순환은
2026-11-08 첫 판정일까지 동결한다. 다음 슬롯이 열릴 때 서울 페이지는 제목 재수정보다 최신
공고의 차종별 지급액·예산 상태·거주 및 출고 조건과 첫 화면 답변을 함께 진단한다.

**사용자 우선순위 — 계산기 정확도**: `테슬라 보조금 계산기`는 101노출·1클릭·CTR 0.99%·
평균 7.45위, `테슬라 할부 계산기`는 72노출·2클릭·CTR 2.78%·평균 8.58위,
`테슬라 계산기`는 88노출·1클릭·CTR 1.14%·평균 6.66위다. 계산기 내부 순환 실험이
2026-11-08까지 동결이고 계산 로직·차량 가격·보조금 원본은 자동 변경 금지 대상이므로 이번
회차에는 수정하지 않는다.
