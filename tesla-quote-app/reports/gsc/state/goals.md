# paytesla 운영 목표

최상위 목표는 사용자가 소유한다. AI 운영 루프는 최상위 목표를 바꾸지 않고,
Search Console 근거에 따라 현재 병목과 중간 목표만 갱신한다.

## 최상위 목표

**테슬라·전기차 구매자가 실제 결정을 내리는 데 필요한 정보를 제공하고,
Google AdSense의 유용한 콘텐츠 기준을 충족해 승인을 받는다.**

## 마일스톤

| # | 마일스톤 | 상태 | 판단 기준 |
|---|---|---|---|
| 1 | 대표 구매 가이드 30편이 모두 공개·색인 가능하고 내부 순환을 갖춤 | 완료 | 콘텐츠 감사와 프로덕션 빌드 통과 |
| 2 | 구매 의도 검색어 5개 이상이 평균순위 10위 이내에서 클릭 발생 | 진행 | 28일 GSC 검색어·페이지 성과 |
| 3 | AdSense 재심사 승인 | 대기 | 콘텐츠 평가 기간과 정책 상태 확인 후 신청 |
| 4 | 월간 자연검색 클릭 100회 | 진행 전 | 28일 클릭 100회 이상 |

## 측정 가능한 것

- GSC 검색 노출·클릭·CTR·평균순위
- 사용자가 검색한 질문과 연결된 랜딩 페이지
- 코드 품질, 정적 페이지 수, 내부 링크, 공식 출처

현재 GA4 행동·AdSense 수익 데이터는 이 루프의 판정 근거로 사용하지 않는다.

2026-08-28 확정 데이터, 최근 28일 기준:

## 현재 병목

### 2026-10-07 자동 운영 판단

**병목**: `/subsidy/seoul`은 28일간 2,220노출·7클릭·CTR 0.32%·평균 7.86위로
비동결 페이지 가운데 노출 대비 클릭 손실이 가장 크다. 연결된 앱의 `서울 테슬라 보조금`은
10노출·1클릭·CTR 10.00%·평균 7.10위로 소표본 클릭이 생겼지만, 페이지 전체 저CTR은
앱과 로컬 페이지 집계에서 같다. 검색어 하나의 개선 신호만으로 페이지 병목이 해소됐다고 보기는
이르다.

**근거**: GSC SEO & Content Planner의 확정 구간은 2026-09-07~10-04, 비교 구간은
2026-08-10~09-06이다. 사이트 전체는 125클릭·10,767노출·CTR 1.16%·평균 7.12위로,
비교 기간보다 클릭 48회·노출 2,496회·CTR 0.23%p가 늘고 평균순위도 0.28위 개선됐다.
필터 없는 전체 비교 접근이며 약 3일의 확정 지연과 상위 반환 행 기반 분석이라는 제한이 있다.
로컬 GSC의 같은 확정 구간은 검색어 차원 21클릭·1,184노출·CTR 1.77%·평균 9.16위·검색어
213개다. 검색어 차원은 익명화 행을 포함하지 않아 사이트 전체 페이지 합계보다 작지만,
서울 페이지 수치와 저CTR 방향은 앱 결과와 일치한다. 최근 7일 노출은 89% 급증해 단기 변동도
함께 관찰한다.

**과거 결정 판정**: 판정 기일이 된 결정은 0건이다. 열린 실험은 4건으로 상한 3건을 이미
넘었으며 신규 결정은 금지된다. 제주 보조금은 2026-10-12, 구매 절차 글은 2026-10-26,
충전 시간은 2026-10-27, 계산기 내부 순환은 2026-11-08 첫 판정일까지 동결한다.

**선택한 조치**: H등급 관찰. 서울 보조금의 검색결과 문구만 고친 과거 D등급 실험은
1,416노출·2클릭·CTR 0.14%로 이미 빗나갔으므로 메타데이터 수정을 반복하지 않는다. 앱도
서울 페이지를 가장 큰 저CTR 후보로 반환했지만 기대 CTR 3%는 휴리스틱일 뿐 보장이 아니다.
현재 페이지는 차종별 보조금·차감 예상가, 조건·예외·FAQ와 계산기·모델·비교 페이지 왕복 링크를
제공한다. 서울시의 2026-09-14 추가 공고는 하반기 보급 물량 확대와 신청 기간을 확인하지만
차량별 지급액 변경을 직접 뜻하지 않는다. 원본 데이터는 자동 변경 금지 대상이므로 공개 콘텐츠,
메타데이터, 내부 링크, 결정 JSON은 변경하지 않는다.

**동결·다음 판단**: 2026-10-12에 제주 보조금 실험을 먼저 판정한다. 이후에도 열린 실험이
3건이면 신규 결정을 추가하지 않는다. 다음 슬롯이 열릴 때 서울 페이지는 제목 재수정보다 승인된
절차로 최신 공고의 차종별 지급액·예산 상태·거주 및 출고 조건을 확인하고 첫 화면 답변과 원본
데이터를 함께 진단한다. 새 정적 페이지는 만들지 않는다.

**사용자 우선순위 — 계산기 정확도**: `테슬라 보조금 계산기`는 107노출·1클릭·평균 7.78위,
`테슬라 할부 계산기`는 57노출·1클릭·평균 8.77위이며, `테슬라 계산기`는 67노출·0클릭·평균
7.1위다. 앱은 세 검색어를 스트라이킹 디스턴스 또는 다중 랜딩 후보로 분류했고 로컬 수집도
계산 의도 124노출·2클릭을 확인했다. 다만 계산기 내부 순환 실험이 2026-11-08까지 동결 중이며
계산 로직·차량 가격·보조금 원본은 자동 변경 금지 대상이므로 이번 회차에는 수정하지 않는다.
