# paytesla 운영 목표

최상위 목표는 사용자가 소유한다. AI 운영 루프는 최상위 목표를 바꾸지 않고,
Search Console 근거에 따라 현재 병목과 중간 목표만 갱신한다.

## 최상위 목표

**테슬라·전기차 구매자가 실제 결정을 내리는 데 필요한 정보를 제공하고,
Google AdSense의 유용한 콘텐츠 기준을 충족해 승인을 받는다.**

## 마일스톤

| # | 마일스톤 | 상태 | 판단 기준 |
|---|---|---|---|
| 1 | 대표 구매 가이드 30편이 모두 공개·색인 가능하고 내부 순환을 갖춤 | 완료 | 콘텐츠 감사와 프로덕션 빌드 통과 |
| 2 | 구매 의도 검색어 5개 이상이 평균순위 10위 이내에서 클릭 발생 | 진행 | 28일 GSC 검색어·페이지 성과 |
| 3 | AdSense 재심사 승인 | 대기 | 콘텐츠 평가 기간과 정책 상태 확인 후 신청 |
| 4 | 월간 자연검색 클릭 100회 | 진행 전 | 28일 클릭 100회 이상 |

## 측정 가능한 것

- GSC 검색 노출·클릭·CTR·평균순위
- 사용자가 검색한 질문과 연결된 랜딩 페이지
- 코드 품질, 정적 페이지 수, 내부 링크, 공식 출처

현재 GA4 행동·AdSense 수익 데이터는 이 루프의 판정 근거로 사용하지 않는다.

## 출발점

2026-08-28 확정 데이터, 최근 28일 기준:

- 클릭 9회
- 노출 730회
- CTR 1.23%
- 평균순위 10.2
- 검색어 111개

## 현재 병목

### 2026-09-27 진단

**병목**: 계산 의도가 구매 단계에 맞는 `/calc` 허브보다 충전비 계산기로 모인다.
`테슬라 계산기`는 28일간 49노출·0클릭·평균 8.3위, 띄어쓰기 없는 `테슬라계산기`는
13노출·0클릭·평균 7.6위였고 두 검색어의 대표 랜딩은 `/calc/charging`이었다. 반면 `/calc`는
같은 기간 검색 노출이 0이었다. 충전비 계산기 자체는 703노출·13클릭·CTR 1.85%·평균 7.2위로
개별 충전비 의도에는 작동하지만, 실구매가·월 부담·유지비·충전비·총소유비용 중 무엇을 계산할지
찾는 사람에게 전체 선택지를 보여주지 못하는 것이 가장 큰 비동결 고객 문제다.

**근거**: 2026-08-28~09-24 검색어 차원은 12클릭·870노출·CTR 1.38%·평균 9.4위다.
페이지 차원 사이트 전체는 87클릭·11,725노출·CTR 0.74%·평균 7.3위다. 계산 의도 전체는
105노출·1클릭이고, 기존 `/calc`에는 계산기 10종과 구매 판단 순서가 이미 있어 새 페이지로
채울 공백이 아니다. 구조를 다시 읽어보니 홈·내비게이션·푸터는 `/calc`를 연결하지만 개별 계산기
공용 교차 링크에는 허브로 돌아오는 링크가 없었다. 또한 허브는 월납입금·유지비·보조금·충전의
판단 조건을 설명하는 기존 대표 가이드와 직접 연결되지 않았다. Tesla 구매 계약은 표시 차량가에
보조금·세금·정부 수수료가 포함되지 않는다고 구분하고, Tesla 홈차징은 운전 습관·주차 장소·차량에
따라 충전 옵션을 검토하도록 안내한다. 무공해차 통합누리집도 충전 조건을 입력하는 요금 시뮬레이터를
별도로 제공한다. 따라서 하나의 고정 숫자보다 여러 계산 흐름을 고르는 허브가 포괄 의도에 맞다.

**과거 결정 판정**: Model Y와 서울 보조금의 D등급 메타데이터 실험은 각각 변경 후 853노출·
0클릭, 1,416노출·2클릭으로 사전 반증 조건을 충족해 모두 `빗나감`으로 닫았다. 제목·설명만
다시 고치지 않고 랜딩 적합성과 내부 구조를 우선한다. 제주 보조금 실험은 2026-09-28 첫 판정일까지
동결을 유지한다.

**선택한 조치**: B등급 내부 순환 개선. 새 페이지, 계산 로직, 원본 데이터, 메타데이터는 바꾸지
않는다. 모든 개별 계산기의 공용 교차 링크에 `/calc`의 `계산기 10종 전체 보기`를 추가하고,
`/calc`에는 월납입금·유지비·보조금 신청·아파트 충전 대표 가이드 4편을 연결했다. 결정
`2026-09-27-calculator-hub-internal-loop`은 2026-11-08 첫 판정일까지 대상 검색어와 두 변경
파일을 동결하며 최종 판정일은 2026-12-06이다.

**다음 판단**: 2026-09-28에 제주 보조금 실험을 먼저 판정한다. 계산기 구조는 동결 기간에 다시
수정하지 않고, 대상 검색어의 랜딩이 `/calc`로 이동하는지와 합계 클릭·CTR을 관찰한다.
