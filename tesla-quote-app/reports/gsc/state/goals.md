# paytesla 운영 목표

최상위 목표는 사용자가 소유한다. AI 운영 루프는 최상위 목표를 바꾸지 않고,
Search Console 근거에 따라 현재 병목과 중간 목표만 갱신한다.

## 최상위 목표

**테슬라·전기차 구매자가 실제 결정을 내리는 데 필요한 정보를 제공하고,
Google AdSense의 유용한 콘텐츠 기준을 충족해 승인을 받는다.**

## 마일스톤

| # | 마일스톤 | 상태 | 판단 기준 |
|---|---|---|---|
| 1 | 대표 구매 가이드 30편이 모두 공개·색인 가능하고 내부 순환을 갖춤 | 완료 | 콘텐츠 감사와 프로덕션 빌드 통과 |
| 2 | 구매 의도 검색어 5개 이상이 평균순위 10위 이내에서 클릭 발생 | 진행 | 28일 GSC 검색어·페이지 성과 |
| 3 | AdSense 재심사 승인 | 대기 | 콘텐츠 평가 기간과 정책 상태 확인 후 신청 |
| 4 | 월간 자연검색 클릭 100회 | 진행 전 | 28일 클릭 100회 이상 |

## 측정 가능한 것

- GSC 검색 노출·클릭·CTR·평균순위
- 사용자가 검색한 질문과 연결된 랜딩 페이지
- 코드 품질, 정적 페이지 수, 내부 링크, 공식 출처

현재 GA4 행동·AdSense 수익 데이터는 이 루프의 판정 근거로 사용하지 않는다.

## 출발점

2026-08-28 확정 데이터, 최근 28일 기준:

- 클릭 9회
- 노출 730회
- CTR 1.23%
- 평균순위 10.2
- 검색어 111개

## 현재 병목

### 2026-09-28 진단

**병목**: `테슬라 출고 예상 사이트`가 28일간 44노출·0클릭·평균 4.0위인데도 홈페이지로
연결되고, 이 질문을 포함하는 기존 대표 글 `/guides/tesla-purchase-process-for-beginners`는
검색 노출이 0이다. 구매자는 별도 예측 사이트가 있는지, 공식 일정은 어디서 확인하는지,
보험·등록·잔금을 언제 맞춰야 하는지를 한 번에 알고 싶지만 기존 글은 계약부터 인도까지의
일반 순서만 설명하고 출고 일정 확인 경로와 확정 조건을 직접 답하지 않았다.

**근거**: 2026-08-29~09-25 검색어 차원은 13클릭·869노출·CTR 1.50%·평균 9.5위다.
페이지 차원 사이트 전체는 88클릭·11,619노출·CTR 0.76%·평균 7.3위다. 대상 검색어는
44노출·0클릭·평균 4.02위이고 대표 글은 0노출이다. Tesla 공식 인도일 안내는 주문 후 계정에서
인도 장소·등록·결제 정보를 확인하고, 차량이 준비되면 일정 예약 연락을 받는다고 설명한다.
주문 FAQ는 일정이 모델·지역·생산·입항 상황에 따라 달라질 수 있다고 밝힌다. 기존 대표 글로
충분히 통합할 수 있어 새 URL을 만들 검색 의도 공백은 아니다.

**과거 결정 판정**: 제주 보조금 D등급 실험은 변경 후 확정 15일간 485노출·1클릭·CTR 0.21%·
평균 5.1위였다. 기준선 1,057노출·12클릭·CTR 1.14%보다 낮지만 사전 반증 표본 500노출에
15회 부족하고 최종 판정일 전이므로 `판정불가`로 2026-10-12까지 14일 연장했다. 최종 판정일은
2026-10-16이다.

**선택한 조치**: C등급 기존 대표 글 심화. 결정
`2026-09-28-delivery-status-guide-depth`를 먼저 기록하고, 구매 절차 글의 첫 답변·설명·핵심
항목에 Tesla 계정과 공식 연락의 역할, 예상 시점이 달라지는 조건, 보험·등록·잔금 준비 시점을
보강했다. Tesla 인도일·주문 FAQ·앱 안내와 무공해차 통합누리집을 공식 출처로 연결했다. 새 페이지,
계산 로직, 차량·가격·보조금 원본 데이터는 변경하지 않았다. 기존 관련 글과 계산기 연결은 유지한다.

**동결·다음 판단**: 구매 절차 글과 대상 검색어는 2026-10-26 첫 판정일까지 동결하며 최종
판정일은 2026-11-23이다. 제주 보조금은 2026-10-12에 다시 판정한다. 계산기 내부 순환 결정은
2026-11-08까지 동결한다. 열린 실험은 3건으로 상한에 도달했으므로 다음 판정 전 신규 결정을
열지 않는다.
