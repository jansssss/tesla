# paytesla 운영 목표

최상위 목표는 사용자가 소유한다. AI 운영 루프는 최상위 목표를 바꾸지 않고,
Search Console 근거에 따라 현재 병목과 중간 목표만 갱신한다.

## 최상위 목표

**테슬라·전기차 구매자가 실제 결정을 내리는 데 필요한 정보를 제공하고,
Google AdSense의 유용한 콘텐츠 기준을 충족해 승인을 받는다.**

## 마일스톤

| # | 마일스톤 | 상태 | 판단 기준 |
|---|---|---|---|
| 1 | 대표 구매 가이드 30편이 모두 공개·색인 가능하고 내부 순환을 갖춤 | 완료 | 콘텐츠 감사와 프로덕션 빌드 통과 |
| 2 | 구매 의도 검색어 5개 이상이 평균순위 10위 이내에서 클릭 발생 | 진행 | 28일 GSC 검색어·페이지 성과 |
| 3 | AdSense 재심사 승인 | 대기 | 콘텐츠 평가 기간과 정책 상태 확인 후 신청 |
| 4 | 월간 자연검색 클릭 100회 | 진행 전 | 28일 클릭 100회 이상 |

## 측정 가능한 것

- GSC 검색 노출·클릭·CTR·평균순위
- 사용자가 검색한 질문과 연결된 랜딩 페이지
- 코드 품질, 정적 페이지 수, 내부 링크, 공식 출처

현재 GA4 행동·AdSense 수익 데이터는 이 루프의 판정 근거로 사용하지 않는다.

## 출발점

2026-08-28 확정 데이터, 최근 28일 기준:

- 클릭 9회
- 노출 730회
- CTR 1.23%
- 평균순위 10.2
- 검색어 111개

## 현재 병목

### 2026-09-04 진단

**병목**: `/subsidy/jeju`는 28일간 1,057노출·12클릭·CTR 1.14%·평균 5.75위로
검색 결과 상단을 확보했지만 순위 대비 클릭 연결이 낮다. 페이지에는 차종별 금액,
기준일, 적용 조건·예외, FAQ, 계산기와 관련 페이지 왕복 링크가 이미 있어 본문 공백보다
검색 결과 제목의 긴 행정구역명과 포괄적인 설명이 제주 구매자의 확인 의도를 흐리는 문제가 먼저 의심된다.

**근거**: 2026-08-05~09-01 검색어 차원은 9클릭·769노출·CTR 1.17%·평균 9.6위다.
익명화 검색어를 포함하는 페이지 차원에서 사이트 전체는 71클릭·7,196노출·CTR 0.99%·평균 7.43위다.
제주 관련 개별 검색어는 GSC 익명화·저표본으로 기준선에 충분히 나타나지 않아 페이지 단위 성과를
주 판정 기준으로 삼았다. `/models/model-y`와 `/subsidy/seoul`의 기존 D등급 실험은 각각
2026-09-25, 2026-09-27까지 동결을 유지하며 이번 조치에서 제외했다.

**선택한 조치**: D등급. 신규 글, 보조금·차량 데이터와 본문을 만들거나 바꾸지 않고
`/subsidy/jeju`에만 적용되는 검색 결과 제목·설명을 제주 테슬라 보조금 확인 의도에 맞게
간결하게 바꿔 CTR 개선 여부를 검증한다.

**지난 회차와 같은가**: 같은 D등급 검색결과 개선이지만 대상 페이지와 검색어는 겹치지 않는다.
