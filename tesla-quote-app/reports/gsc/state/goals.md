# paytesla 운영 목표

최상위 목표는 사용자가 소유한다. AI 운영 루프는 최상위 목표를 바꾸지 않고,
Search Console 근거에 따라 현재 병목과 중간 목표만 갱신한다.

## 최상위 목표

**테슬라·전기차 구매자가 실제 결정을 내리는 데 필요한 정보를 제공하고,
Google AdSense의 유용한 콘텐츠 기준을 충족해 승인을 받는다.**

## 마일스톤

| # | 마일스톤 | 상태 | 판단 기준 |
|---|---|---|---|
| 1 | 대표 구매 가이드 30편이 모두 공개·색인 가능하고 내부 순환을 갖춤 | 완료 | 콘텐츠 감사와 프로덕션 빌드 통과 |
| 2 | 구매 의도 검색어 5개 이상이 평균순위 10위 이내에서 클릭 발생 | 진행 | 28일 GSC 검색어·페이지 성과 |
| 3 | AdSense 재심사 승인 | 대기 | 콘텐츠 평가 기간과 정책 상태 확인 후 신청 |
| 4 | 월간 자연검색 클릭 100회 | 진행 전 | 28일 클릭 100회 이상 |

## 측정 가능한 것

- GSC 검색 노출·클릭·CTR·평균순위
- 사용자가 검색한 질문과 연결된 랜딩 페이지
- 코드 품질, 정적 페이지 수, 내부 링크, 공식 출처

현재 GA4 행동·AdSense 수익 데이터는 이 루프의 판정 근거로 사용하지 않는다.

## 출발점

2026-08-28 확정 데이터, 최근 28일 기준:

- 클릭 9회
- 노출 730회
- CTR 1.23%
- 평균순위 10.2
- 검색어 111개

## 현재 병목

### 2026-09-29 수동 보완 결정

**병목**: `/calc/charging-time`은 28일간 882노출·8클릭·CTR 0.91%·평균 6.51위로
순위를 확보했지만 클릭 연결이 약하다. `7kw 완속 충전기 충전 시간`은 19노출·0클릭·평균
7.47위, `급속 충전이랑 완속 충전 실제로 얼마나 걸려?`는 18노출·0클릭·평균 9.94위다.
기존 페이지는 계산기와 충전 곡선 설명을 제공하지만 7kW 즉답과 같은 조건의 출력별 비교가
첫 화면에 없어 검색자가 클릭 전에 기대하는 답이 선명하지 않다.

**근거**: GSC SEO & Content Planner의 2026-08-30~09-26 확정 데이터에서 사이트 전체는
86클릭·11,253노출·CTR 0.76%·평균 7.19위다. 대상 페이지 CTR은 도구가 제시한 저CTR 후보에
포함됐고, 두 핵심 검색어의 노출은 각각 이전 대비 19회·14회 증가했다. Tesla 공식 홈차징·
온보드 차저 자료는 Model 3·Y RWD의 AC 최대 7kW, Long Range·Performance의 최대 10.5kW,
모바일 커넥터의 3kW를 구분한다. 새 URL보다 기존 계산기의 즉답과 예시를 심화할 근거가 충분하다.

**과거 결정 판정**: 판정 기일이 된 결정은 0건이다. 기존 세 동결 대상은 그대로 유지한다.

**선택한 조치**: C등급 기존 계산기 콘텐츠 심화. 결정
`2026-09-29-charging-time-guide-depth`를 먼저 기록하고, 7kW 완속·급속·수퍼차저 검색 의도를
제목·설명·첫 답변과 출력별 산술 비교에 반영한다. 공식 조건과 실제 충전곡선의 예외를 분리하고
급속 충전 준비물 답변과 왕복 링크를 만든다. 계산 공식과 원본 데이터는 변경하지 않는다.

**상한 예외**: 사용자가 이번 제안의 수정과 커밋·푸시를 명시 승인해 열린 실험 상한 3건에 대한
이번 회차 한정 예외로 4번째 결정을 연다. 예약 자동화는 이후에도 상한 3건 규칙을 유지한다.

**동결·다음 판단**: 충전 시간 페이지와 세 대상 검색어는 2026-10-27 첫 판정일까지 동결하며
최종 판정일은 2026-11-24다. 제주 보조금은 2026-10-12, 구매 절차 글은 2026-10-26,
계산기 내부 순환은 2026-11-08 첫 판정일을 유지한다.
