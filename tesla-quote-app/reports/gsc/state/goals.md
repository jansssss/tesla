# paytesla 운영 목표

최상위 목표는 사용자가 소유한다. AI 운영 루프는 최상위 목표를 바꾸지 않고,
Search Console 근거에 따라 현재 병목과 중간 목표만 갱신한다.

## 최상위 목표

**테슬라·전기차 구매자가 실제 결정을 내리는 데 필요한 정보를 제공하고,
Google AdSense의 유용한 콘텐츠 기준을 충족해 승인을 받는다.**

## 마일스톤

| # | 마일스톤 | 상태 | 판단 기준 |
|---|---|---|---|
| 1 | 대표 구매 가이드 30편이 모두 공개·색인 가능하고 내부 순환을 갖춤 | 완료 | 콘텐츠 감사와 프로덕션 빌드 통과 |
| 2 | 구매 의도 검색어 5개 이상이 평균순위 10위 이내에서 클릭 발생 | 진행 | 28일 GSC 검색어·페이지 성과 |
| 3 | AdSense 재심사 승인 | 대기 | 콘텐츠 평가 기간과 정책 상태 확인 후 신청 |
| 4 | 월간 자연검색 클릭 100회 | 진행 전 | 28일 클릭 100회 이상 |

## 측정 가능한 것

- GSC 검색 노출·클릭·CTR·평균순위
- 사용자가 검색한 질문과 연결된 랜딩 페이지
- 코드 품질, 정적 페이지 수, 내부 링크, 공식 출처

현재 GA4 행동·AdSense 수익 데이터는 이 루프의 판정 근거로 사용하지 않는다.

## 출발점

2026-08-28 확정 데이터, 최근 28일 기준:

- 클릭 9회
- 노출 730회
- CTR 1.23%
- 평균순위 10.2
- 검색어 111개

## 현재 병목

### 2026-09-15 진단

**병목**: 포괄적인 `테슬라 계산기` 검색이 구매 단계에 맞는 계산기 허브보다
`/calc/charging`으로 연결된다. `테슬라 계산기`는 28일간 56노출·0클릭·평균 8.9위,
띄어쓰기 없는 `테슬라계산기`는 18노출·0클릭·평균 8.4위였고 두 검색어 모두 충전비 계산기로
연결됐다. 충전비 계산기 페이지 전체는 555노출·13클릭·CTR 2.34%·평균 7.6위였다. 충전비
계산기 자체의 클릭은 늘었지만, 실구매가·월 부담·충전비·총소유비용 중 무엇을 계산할지 찾는
포괄 검색 의도는 여전히 허브로 연결되지 않는 것이 현재 가장 큰 비동결 고객 문제다.

**근거**: 2026-08-16~09-12 검색어 차원은 11클릭·876노출·CTR 1.26%·평균 9.5위다.
계산 의도 전체는 112노출·0클릭이었다. 기존 `/calc` 허브에는 계산기 10종과 구매 판단 순서가
있고, 대표 글 `/guides/tesla-monthly-payment-guide`와
`/guides/tesla-ev-maintenance-cost`가 월납입금·유지비 의도를 나눠 설명한다.
`/calc/charging` 역시 주행거리·전비·급속/완속 비율·단가·겨울 조건과 다른 계산기 9종 링크를
갖춰 새 글로 채울 공백은 아니다.
Tesla는 홈 충전을 편리하고 경제적인 일상 충전 방식으로 안내하고, 수퍼차저 요금은 충전소별
동적 요금과 부하 시간대에 따라 달라지며 수시로 바뀔 수 있다고 명시한다. 무공해차 통합누리집은
2026-08-01부터 기후부 공공 충전요금을 출력별 5단계 295~393.1원/kWh로 구분하고, 현재 요금
화면은 사업자·요금유형·용량별 조회를 제공한다. 기후에너지환경부는 2026-09-05~10-31
주말·공휴일 11~14시에 전력량요금 50% 할인과 기후부 공공 급속충전기 최대 32% 한시 할인을
시행하며, 민간 사업자는 할인 폭과 방식이 서로 다르다고 밝혔다. 따라서 고정 요금을 단정하는
새 페이지보다 사용자가 실제 단가와 충전 비율을 넣는 기존 계산기 구조가 적합하다.

**선택한 조치**: H등급 관찰. `2026-09-01-model-y-serp-ctr`,
`2026-09-03-seoul-subsidy-serp-ctr`, `2026-09-04-jeju-subsidy-serp-ctr` 세 실험이 모두
열려 있어 상한 3건에 도달했다. 판정 기일 전에는 신규 결정·공개 콘텐츠·메타데이터·내부 링크를
변경하지 않고 이번 GSC 관측만 보존한다.

**다음 판단**: 첫 슬롯이 열리는 2026-09-25 이후에도 포괄 계산 검색어가 50노출 이상에서
무클릭이고 `/calc`보다 개별 계산기나 홈으로 계속 분산되면, 중복 페이지 신설 없이 `/calc` 허브의
검색결과 문구와 기존 왕복 링크를 우선 검토한다.
