# paytesla 운영 목표

최상위 목표는 사용자가 소유한다. AI 운영 루프는 최상위 목표를 바꾸지 않고,
Search Console 근거에 따라 현재 병목과 중간 목표만 갱신한다.

## 최상위 목표

**테슬라·전기차 구매자가 실제 결정을 내리는 데 필요한 정보를 제공하고,
Google AdSense의 유용한 콘텐츠 기준을 충족해 승인을 받는다.**

## 마일스톤

| # | 마일스톤 | 상태 | 판단 기준 |
|---|---|---|---|
| 1 | 대표 구매 가이드 30편이 모두 공개·색인 가능하고 내부 순환을 갖춤 | 완료 | 콘텐츠 감사와 프로덕션 빌드 통과 |
| 2 | 구매 의도 검색어 5개 이상이 평균순위 10위 이내에서 클릭 발생 | 진행 | 28일 GSC 검색어·페이지 성과 |
| 3 | AdSense 재심사 승인 | 대기 | 콘텐츠 평가 기간과 정책 상태 확인 후 신청 |
| 4 | 월간 자연검색 클릭 100회 | 진행 전 | 28일 클릭 100회 이상 |

## 측정 가능한 것

- GSC 검색 노출·클릭·CTR·평균순위
- 사용자가 검색한 질문과 연결된 랜딩 페이지
- 코드 품질, 정적 페이지 수, 내부 링크, 공식 출처

현재 GA4 행동·AdSense 수익 데이터는 이 루프의 판정 근거로 사용하지 않는다.

## 출발점

2026-08-28 확정 데이터, 최근 28일 기준:

- 클릭 9회
- 노출 730회
- CTR 1.23%
- 평균순위 10.2
- 검색어 111개

## 현재 병목

### 2026-09-01 진단

**병목**: 보조금·자동차세·충전비는 클릭이 이어지지만 모델정보 의도는 노출 대비 클릭
연결이 가장 약하다. 특히 `/models/model-y`는 28일간 641노출·0클릭·평균 8.9위로,
본문 공백보다 검색 결과 제목·설명의 약속이 길고 분산된 문제가 먼저 의심된다.

**근거**: 2026-08-02~08-29 검색어 차원은 10클릭·756노출·CTR 1.32%·평균 10.1위다.
모델정보 의도는 98노출·0클릭이고, 익명화 검색어를 포함하는 페이지 차원에서
`/models/model-y`는 641노출·0클릭이다. 같은 기간 사이트 전체 페이지 차원은
75클릭·6,827노출·CTR 1.10%·평균 7.4위다.

**선택한 조치**: D등급. 신규 글이나 차량 데이터를 만들지 않고 `/models/model-y`의
검색 결과 제목·설명만 간결하게 바꿔 CTR 개선 여부를 검증한다.

**지난 회차와 같은가**: 초기의 넓은 모델정보 병목을 실제 랜딩 페이지 한 곳으로 좁혔다.
