# paytesla 운영 목표

최상위 목표는 사용자가 소유한다. AI 운영 루프는 최상위 목표를 바꾸지 않고,
Search Console 근거에 따라 현재 병목과 중간 목표만 갱신한다.

## 최상위 목표

**테슬라·전기차 구매자가 실제 결정을 내리는 데 필요한 정보를 제공하고,
Google AdSense의 유용한 콘텐츠 기준을 충족해 승인을 받는다.**

## 마일스톤

| # | 마일스톤 | 상태 | 판단 기준 |
|---|---|---|---|
| 1 | 대표 구매 가이드 30편이 모두 공개·색인 가능하고 내부 순환을 갖춤 | 완료 | 콘텐츠 감사와 프로덕션 빌드 통과 |
| 2 | 구매 의도 검색어 5개 이상이 평균순위 10위 이내에서 클릭 발생 | 진행 | 28일 GSC 검색어·페이지 성과 |
| 3 | AdSense 재심사 승인 | 대기 | 콘텐츠 평가 기간과 정책 상태 확인 후 신청 |
| 4 | 월간 자연검색 클릭 100회 | 진행 전 | 28일 클릭 100회 이상 |

## 측정 가능한 것

- GSC 검색 노출·클릭·CTR·평균순위
- 사용자가 검색한 질문과 연결된 랜딩 페이지
- 코드 품질, 정적 페이지 수, 내부 링크, 공식 출처

현재 GA4 행동·AdSense 수익 데이터는 이 루프의 판정 근거로 사용하지 않는다.

## 현재 병목

### 2026-10-01 자동 운영 판단

**병목**: `/subsidy/seoul`은 28일간 2,996노출·7클릭·CTR 0.23%·평균 7.90위로
비동결 페이지 가운데 노출 대비 클릭 손실이 가장 크다. 연결된 앱에서 `서울 테슬라 보조금`은
11노출·0클릭·평균 6.45위였고, 로컬 수집에서도 `테슬라 서울 보조금`은 16노출·0클릭·평균
5.8위여서 검색결과 상단 노출이 방문으로 충분히 이어지지 않는 방향이 일치한다.

**근거**: GSC SEO & Content Planner의 확정 구간은 2026-09-01~09-28, 비교 구간은
2026-08-04~08-31이다. 사이트 전체는 100클릭·11,439노출·CTR 0.87%·평균 7.18위로,
비교 기간보다 클릭 27회·노출 4,674회가 늘고 평균순위는 0.21위 개선됐지만 CTR은 0.20%p
낮아졌다. 필터 없는 전체 비교 접근이며 약 3일의 확정 지연과 상위 반환 행 기반 분석이라는
제한이 있다. 로컬 GSC의 같은 확정 구간은 검색어 차원 14클릭·964노출·CTR 1.45%·평균
9.58위·검색어 183개로, 페이지 차원 병목과 검색어 차원 저CTR 방향을 교차 확인했다.

**과거 결정 판정**: 판정 기일이 된 결정은 0건이다. 열린 실험은 4건으로 상한 3건을 이미
넘었으며 신규 결정은 금지된다. 제주 보조금은 2026-10-12, 구매 절차 글은 2026-10-26,
충전 시간은 2026-10-27, 계산기 내부 순환은 2026-11-08 첫 판정일까지 동결한다.

**선택한 조치**: H등급 관찰. 서울 보조금의 검색결과 문구만 고친 과거 D등급 실험은 이미
1,416노출·2클릭·CTR 0.14%로 빗나갔으므로 같은 메타데이터 수정을 반복하지 않는다. 현재
페이지는 Model 3·Y 차종별 보조금과 차감 예상가, 조건·예외·FAQ, 보조금 계산기·모델·비교
페이지 왕복 링크를 제공한다. 다만 원본 보조금 기준일은 2026-07-01이고 서울시는 2026-09-14
하반기 추가 공고로 보급 물량을 확대했으므로, 다음 변경 전에는 승인된 원본 데이터 갱신 절차로
금액·예산 상태를 먼저 검증해야 한다. 원본 데이터 자동 변경 금지와 신규 결정 상한을 지켜 공개
콘텐츠·메타데이터·내부 링크·결정 JSON은 변경하지 않고 이번 관측만 기록한다.

**동결·다음 판단**: 2026-10-12에 제주 보조금 실험을 먼저 판정한다. 슬롯이 열리면 서울
페이지는 제목 재수정보다 최신 추가 공고 반영 여부, 지급대상 차종·거주 및 출고 조건, 실제
검색어별 첫 화면 답변을 한 묶음으로 진단한다. 새 정적 페이지는 만들지 않는다.

**사용자 우선순위 — 계산기 정확도**: `테슬라 보조금 계산기`는 127노출·2클릭·평균 7.73위,
`테슬라 할부 계산기`는 52노출·1클릭·평균 8.96위이며, 로컬 수집의 `테슬라 계산기`도
57노출·0클릭·평균 8.1위다. 수요는 확인됐지만 현재 계산기 내부 순환 실험이 2026-11-08까지
동결 중이고 계산 로직·차량 가격·보조금 원본 데이터는 자동 변경 금지 대상이므로 이번 회차에는
수정하지 않는다. 해당 실험 판정 뒤 사용자 승인 범위에서 (1) Tesla 차량·옵션가와 보조금
스냅샷 기준일 갱신, (2) 보조금 차감 차량가와 취득세·등록 관련 비용을 분리한 인도 시 필요금액,
(3) 원리금균등 월납입금·총이자·초기 현금을 함께 보여주는 금융 명세, (4) 공식 예시 기반
회귀 테스트 순으로 정확도 개선 결정을 검토한다. Tesla 계약상 세금·수수료는 등록지와 인도
시점에 따라 달라지므로 확정액이 아니라 근거·기준일·변동 범위를 분리해 표시한다.
