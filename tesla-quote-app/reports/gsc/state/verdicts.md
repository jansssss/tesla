# GSC 결정 판정 이력

최신 판정을 위에 기록한다. 각 기록은 가설, 실측, 사이트 전체 변화로 보정한 판정,
다음 판단에 재사용할 학습을 포함해야 한다.

## 2026-09-27 — Model Y 검색결과 문구

- 결정: `2026-09-01-model-y-serp-ctr`
- 판정: **빗나감**
- 가설: Model Y 제목·설명을 짧고 비교 중심으로 바꾸면 이미 확보한 순위에서 클릭이 늘어난다.
- 실측: 변경 후 확정 17일간 853노출·0클릭·CTR 0.00%·평균순위 8.5위였다. 기준선은
  28일간 641노출·0클릭·CTR 0.00%·평균순위 8.9위였다.
- 보정: 같은 기간 사이트 전체 평균순위 개선을 빼면 대상 순위 변화는 -0.2위에 그쳤다.
- 판단: 노출 200회 이상에서 CTR 0.5% 미만이라는 사전 반증 조건을 충족했다. 제목·설명만으로는
  Model Y 검색 노출을 클릭으로 연결하지 못했다.
- 학습: 모델 페이지의 무클릭을 다시 다룰 때는 같은 메타데이터 수정 반복보다 검색어별 랜딩 적합성,
  첫 화면의 실제 비교 답변, 모델 허브와의 내부 연결을 함께 점검한다.

## 2026-09-27 — 서울 보조금 검색결과 문구

- 결정: `2026-09-03-seoul-subsidy-serp-ctr`
- 판정: **빗나감**
- 가설: 서울·테슬라·보조금을 제목 앞에 모으고 금액 확인 목적을 설명하면 클릭이 늘어난다.
- 실측: 변경 후 확정 15일간 1,416노출·2클릭·CTR 0.14%·평균순위 7.8위였다. 기준선은
  28일간 2,447노출·10클릭·CTR 0.41%·평균순위 7.4위였다.
- 보정: 사이트 전체 평균순위 변화를 빼면 대상 순위는 +0.7위였고 CTR은 0.27%p 낮아졌다.
- 판단: 노출 1,000회 이상에서 CTR 0.5% 미만이라는 사전 반증 조건을 충족했다. 검색결과 문구만
  바꿔서는 서울 보조금 노출을 클릭으로 연결하지 못했다.
- 학습: 지역 보조금 페이지는 메타데이터를 반복 수정하기보다 데이터 최신성, 차종별 즉답,
  실제 검색어와 랜딩의 일치 여부를 먼저 진단한다.
